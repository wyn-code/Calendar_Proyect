# Calendar Pro — Agenda de Turnos

> **EN** A mobile-first appointment-scheduling web app for a medical practice: a monthly calendar to book, edit and export patient appointments.
>
> **ES** Aplicación web mobile-first para agenda de turnos de un consultorio: un calendario mensual para cargar, editar y exportar los turnos de los pacientes.

---

## Features / Características

- **Monthly calendar grid** (6×7) with Spanish weekday headers and month navigation — _grilla mensual con encabezados en español y navegación entre meses_.
- **Book appointments by tapping a day**: start time, patient name with server-side autocomplete, consultation type (Particular / Obra Social), obra social selector and optional notes — _formulario por día con autocompletado de pacientes y tipo de consulta_.
- **Edit / reassign / delete** appointments from a per-day detail view, sorted by hour — _editar, reasignar o eliminar turnos desde el detalle del día_.
- **Color-coded coverage badges** (P / O.S) to scan the month at a glance — _chips de color para diferenciar cobertura_.
- **Export the monthly session plan to PDF** (generated by the backend) — _exportación de la planilla mensual de sesiones a PDF_.
- **Patients directory page** with obra social, phone and notes — _listado de pacientes con su obra social_.
- **Authentication**: JWT login modal with persistent session and logout — _login con token persistente y cierre de sesión_.
- **Mobile-first, responsive** UI designed to be used from a phone — _diseño pensado para cargar turnos desde el celular_.

## Tech Stack / Stack tecnológico

| Layer         | Technology                                                               |
| ------------- | ------------------------------------------------------------------------ |
| Framework     | React 19 + TypeScript (strict) + Vite 8                                  |
| SSR / Routing | TanStack Start (file-based routing, SSR) + TanStack Router               |
| Server state  | TanStack Query (fetch, cache & invalidation)                             |
| Styling       | Tailwind CSS 4 + shadcn/ui (Radix primitives, CVA, tailwind-merge)       |
| UX            | sonner (toasts), lucide-react (icons)                                    |
| Dates         | Native `Date` + typed utilities in `src/lib/turnos.ts` (no date library) |
| Backend       | External FastAPI service at `/api/v1` (JWT auth, proxied in dev)         |

## Architecture / Arquitectura

- **File-based routes** under `src/routes/` (`__root.tsx` shell, `/` calendar, `/pacientes` directory).
- **Data layer**: custom hooks (`use-appointments`, `use-patients`, `use-obra-sociales`) wrap typed React Query queries/mutations, invalidating caches on write.
- **API client**: thin typed wrapper in `src/lib/api.ts` over `fetch` with JWT injection and normalized error messages.
- **Domain mapping**: `src/lib/turnos.ts` transforms raw API models (`Appointment`, `Patient`, `ObraSocial`) into the `Turno` view model consumed by the UI.
- **Resilience**: SSR error boundaries and h3 error-capture (`src/server.ts`, `src/start.ts`, `src/lib/error-capture.ts`) render a fallback page on 500s instead of leaking stack traces.

```
src/
├── routes/          # TanStack file-based routes
├── components/
│   ├── auth/        # LoginModal
│   ├── layout/      # PageShell (shared background shell)
│   ├── turnos/      # CalendarGrid, TurnoDialog, DayDetailDialog, comboboxes…
│   └── ui/          # shadcn/ui primitives (only the ones in use)
├── hooks/           # React Query hooks (appointments, patients, obra sociales)
└── lib/             # api, auth, config, turnos (domain mapping), error handling
```

## Getting started / Puesta en marcha

Requirements: **Node.js 20+** (works with npm or [bun](https://bun.sh)).

```sh
git clone <repository-url>
cd Calendar_Proyect
npm install
npm run dev
```

The app expects a **FastAPI backend** on `http://127.0.0.1:8000`. In dev, Vite proxies `/api` to it (no CORS issues); otherwise point `VITE_API_URL` to your backend.

Endpoints consumed: `/api/v1/appointments`, `/api/v1/patients`, `/api/v1/obra-social`, `/api/v1/auth/login`, `/api/v1/export/planilla-sesiones`.
